# Front (PWA)

Déposer ici les fichiers du front de production (issus de l'adaptation de la
maquette `CRADESC_Intranet.html`). Le point d'entrée doit être `index.html`.

`firebase.json` sert ce dossier et renvoie toutes les routes vers `index.html`
(application web). Voir `docs/03_integration_maquette.md` pour la marche à suivre.
